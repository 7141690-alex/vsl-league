## 1. Общее описание

**VSL** — веб-приложение для управления волейбольной лигой. Отображает:
- Турнирную таблицу по каждой лиге
- Расписание матчей
- Составы команд
- Профили игроков
- Номинации и награды

Приложение доступно по адресу: **https://vsl-league.vercel.app**

Работает на мобильных телефонах и компьютерах. Может быть установлено как приложение на главный экран.

## 2. Публичная часть сайта

### 2.1 Турнирная таблица

Открывается по умолчанию при входе на сайт.

**Переключение между лигами** — кнопки в верхней части экрана (например, «♂ Мужская», «♀ Женская»). Список лиг формируется администратором.

**Колонки таблицы:**
| Колонка | Обозначение | Значение |
|---------|-------------|----------|
| # | — | Место в таблице |
| И | Игры | Сыграно матчей |
| В | Победы | Количество побед |
| П | Поражения | Количество поражений |
| СВ | Сеты выиграны | |
| СП | Сеты проиграны | |
| Очки | — | Набранные очки |

**Система начисления очков:**
- Победа 3:0 или 3:1 → **3 очка** победителю, **0** проигравшему
- Победа 3:2 → **3 очка** победителю, **1 очко** проигравшему

**Цветные полосы:**
- Синяя — зона плей-офф (топ-3)
- Красная — зона вылета (последние 2)

**Нажатие на строку команды** открывает страницу этой команды.

---

### 2.2 Расписание

Переключается кнопкой «Расписание» в шапке.

Матчи сгруппированы по неделям и датам. Отображается:
- Дата и время
- Команды
- Зал
- Счёт (для завершённых матчей)
- Ссылка на фотоотчёт и видеозапись (если добавлены)

---

### 2.3 Страница команды

Открывается по нажатию на строку команды в таблице.

Показывает:
- Фото команды (если загружено)
- Список игроков с номерами, ростом, признаком капитана
- Предстоящие матчи
- Сыгранные матчи с результатами

Нажатие на имя игрока открывает страницу игрока.

---

### 2.4 Страница игрока

Показывает:
- Имя и пол игрока
- Знаки номинаций, полученных игроком
- Рост
- Текущая команда
- Список всех наград (номинаций) с датами и статистикой

Кнопка «← Назад» возвращает на страницу команды.

---

### 2.5 Номинации (виджет)

Расположен под турнирной таблицей. Показывает последние полученные награды игроков лиги.

**Нажатие на заголовок «Номинации»** — переходит на полную страницу номинаций этой лиги.

---

### 2.6 Страница Номинации

Открывается при нажатии на заголовок виджета «Номинации».

Показывает все номинации лиги с возможностью фильтрации по типу награды:
- Все
- MVP
- Лучший пассующий
- Лучший подающий
- Лучший атакующий
- Лучший либеро

В шапке — краткая статистика по количеству наград каждого типа.

## 3. Панель администратора

Доступна по нажатию кнопки **⚙ ADMIN** в правом верхнем углу.

### 3.1 Вход в систему

Введите email и пароль администратора. Учётные записи создаются через Supabase Dashboard (см. раздел 5).

Кнопка **«Выйти»** завершает сессию.

---

### 3.2 Вкладка «Команды»

#### Создание команды

Заполните форму «Создать команду»:

| Поле | Описание |
|------|----------|
| **Название** | Полное название команды |
| **Лига** | Выберите лигу из списка (берётся из вкладки «Лиги») |
| **Фото** | Путь к файлу фото, напр. `/teams/Unity.jpg` (файл должен быть в папке `public/teams/`) |
| **Участвует в текущем сезоне** | Снимите галочку, если команда не играет в этом сезоне |

Нажмите **«Создать команду»**.

#### Редактирование команды

Нажмите **«Изменить»** рядом с командой. Можно изменить название, лигу, фото и статус активности.

#### Неактивные команды

Команды, у которых снят флаг «Активна», помечаются как неактивные. Кнопка **«Показать неактивные»** позволяет их просмотреть.

> Совет: если команда переходит в другую лигу — измените поле «Лига» в редактировании. Если не играет в сезоне — снимите галочку «Активна».

---

### 3.3 Вкладка «Игры»

#### Добавление игры

Форма в верхней части. Поля:

| Поле | Описание |
|------|----------|
| **Лига** | Мужская / Женская / другая |
| **Дата и время** | По умолчанию — следующее воскресенье в 12:00 |
| **Зал** | Название зала. Предлагаются ранее введённые |
| **Хозяева / Гости** | Выбрать из команд выбранной лиги |
| **Статус** | Запланирован / Завершён |
| **Счёт** | Видимо только для завершённых. Формат: сеты (0–3) |
| **Счёт по сетам** | Автоматически появляется нужное количество строк |
| **Фотоотчёт / Видео** | Ссылки на Google Photos / YouTube |

Нажмите **«Добавить»**.

#### Редактирование игры

Нажмите **«Изменить»** — форма заполнится данными выбранной игры. Нажмите **«Сохранить»**.

---

### 3.4 Вкладка «Игроки»

#### Создание игрока

Форма «Создать игрока»:

| Поле | Описание |
|------|----------|
| **Имя** | Фамилия и имя |
| **Пол** | ♂ Мужской / ♀ Женский |
| **Дата рождения** | Необязательно |
| **Рост** | В сантиметрах, необязательно |

#### Добавление в команду

После создания игрока нажмите **«+ Команда»**. Заполните:
- Команда
- Номер (необязательно)
- Дата начала
- Капитан (чекбокс)

У команды может быть только один капитан. При назначении нового предыдущий снимается автоматически.

#### Убрать из команды

Нажмите **«Убрать из команды»** — игрок получит дату выхода, но останется в базе.

---

### 3.5 Вкладка «Награды»

#### Выдача награды

Форма «Выдать награду»:

| Поле | Описание |
|------|----------|
| **Лига** | Для какой лиги награда |
| **Номинация** | MVP, Лучший пассующий, Лучший подающий, Лучший атакующий, Лучший либеро |
| **Команда** | Выбрать команду |
| **Игрок** | Список появляется после выбора команды |
| **Дата игры** | За какую игру выдаётся |
| **Статистика** | Для не-MVP: пасов / эйсов / очков / % |

Значки наград автоматически отображаются на странице игрока и в виджете «Номинации».

#### Удаление награды

Нажмите **«Удалить»** рядом с наградой в списке.

---

### 3.6 Вкладка «Лиги»

Управление лигами, которые отображаются в переключателе на главном экране.

#### Создание лиги

| Поле | Описание |
|------|----------|
| **Системное имя (slug)** | Уникальный идентификатор, только латиница и `_`. Напр.: `beach_male` |
| **Отображаемое название** | Как лига называется на сайте. Напр.: «Пляжная мужская» |
| **Тип** | Мужская / Женская / Смешанная |

> **Важно:** после создания лиги при добавлении команд и игр выбирайте эту лигу в выпадающем списке — они автоматически отображаются в нужном переключателе.

#### Деактивация лиги

В редактировании снимите галочку **«Активна»** — лига перестанет показываться в переключателе на сайте, но данные сохранятся.

**Предустановленные лиги** (`male` и `female`) — удалять их не рекомендуется, так как большинство команд и игр привязаны к этим слагам.

---

### 3.7 Вкладка «Журнал»

Показывает историю всех действий администраторов.

**Каждая запись содержит:**
- Тип действия (цветная метка): Добавлено, Изменено, Удалено, Добавлен в команду, Убран из команды
- Тип объекта: команда, игра, игрок, награда, лига
- Название объекта
- Email администратора
- Дата и время

**Фильтрация** — кнопки по типу действия.

Журнал хранит последние **300 записей**.

## 4. Установка как приложение (PWA)

VSL поддерживает установку как приложение на главный экран.

### Android / Chrome
При первом визите появится баннер «Установить приложение». Нажмите **«Установить»**.

### iPhone / Safari
1. Откройте сайт в Safari
2. Нажмите кнопку **⎋** (Поделиться) внизу экрана
3. Выберите **«На экран "Домой"»**

После установки приложение открывается без браузерной строки, как нативное приложение.

### Таблицы базы данных

| Таблица | Назначение |
|---------|------------|
| `teams` | Команды (name, league, photo_url, active) |
| `players` | Игроки (name, gender, height, birth_date) |

| `activity_log` | Журнал действий администраторов |

### SQL для ручных миграций

```sql
-- Добавить таблицу журнала (если ещё нет)
CREATE TABLE IF NOT EXISTS activity_log (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_email text NOT NULL,
  action text NOT NULL,
  entity_type text NOT NULL,
  entity_name text,
  details jsonb DEFAULT '{}',
  created_at timestamptz DEFAULT now()
);

-- Добавить таблицу лиг (если ещё нет)
CREATE TABLE IF NOT EXISTS leagues (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  name text NOT NULL UNIQUE,
  display_name text NOT NULL,
  gender text NOT NULL DEFAULT 'male',
  active boolean DEFAULT true,
  created_at timestamptz DEFAULT now()
);

-- Начальные данные лиг
INSERT INTO leagues (name, display_name, gender)
VALUES ('male', 'Мужская', 'male'), ('female', 'Женская', 'female')
ON CONFLICT (name) DO NOTHING;

-- Поле active для команд (если ещё нет)
ALTER TABLE teams ADD COLUMN IF NOT EXISTS active boolean DEFAULT true;
```
